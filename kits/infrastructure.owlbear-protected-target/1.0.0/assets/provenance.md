# Owlbear source and artifact provenance

The source authority is [Brad-Edwards/owlbear](https://github.com/Brad-Edwards/owlbear).
The reference revision is `fa4497f3273517611e2d62f5fb32c620a00a9681`.
Its README identifies Owlbear as version 2.3.0 and a non-production prototype.
The source uses the MIT license, Copyright (c) 2026 Brad Edwards.
This kit contains original declarations and documentation; it bundles no upstream code.

## Required artifact inputs

Each RAES source selector uses the reference revision as its version coordinate.
These are logical build-output selectors, not claims of published binary availability.
Backend preparation must admit the actual outputs and preserve their build provenance.

The daemon build includes the eBPF skeletons generated by the upstream eBPF Makefile.
No separate eBPF runtime file is required by this release.
The upstream reference platform is ARM64 Ubuntu 24.04 with Linux kernel 6.17.
Kernel module ABI, BTF, BPF LSM, runtime libraries, and hardware checks require independent verification.
No cloud platform, pre-provisioned instance, or private deployment information is included.

The component inventory marks binary identities as unresolved.
A source revision is not a binary digest, signature, or dependency SBOM.
The release manifest binds the shipped kit files and their canonical SDL parent.
It does not establish authenticity or bind external build outputs that are not shipped.
