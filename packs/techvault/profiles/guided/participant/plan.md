# Guided plan

1. Inventory the interfaces reachable from Kali and classify the DMZ,
   internal, and security-facing surfaces you can observe.
2. Inspect the customer portal as a user would. Compare normal and malformed
   authentication behavior before escalating.
3. Follow only evidence discovered in-world toward identity, data, workstation,
   and file-sharing services.
4. Keep a timestamped activity log and note which actions should be visible to
   network and host monitoring.
5. At each checkpoint, pause for a red/blue comparison before continuing.

The exercise rewards defensible reasoning and evidence preservation; there is
no flag submission or points board in this scenario definition.
