# Support

Use [GitHub issues](https://github.com/OpenRAE/env-packs/issues) for bug
reports, feature requests, and questions about the pack format or tools. This is
a single-maintainer project with no support SLA — issues are answered
best-effort. There is no commercial support channel.

Found a security vulnerability? Do not open a public issue — follow
[SECURITY.md](SECURITY.md) instead.

## Reporting a bug

Include:

- what you ran and what happened, with the exact error;
- the affected contract, schema, template, or tool; and
- your `raes-env-packs` and Python versions.

## Proposing a change

Say what you want to do and why, and whether it changes the pack format or only
its documentation or tooling. For anything touching the contract or a schema,
open an issue before a pull request so the design can be agreed first.
