# ACES content sources

`onboarding/` is the pack-contained source directory referenced by the
`fileshare-onboarding-packet` ACES content resource. The backend must realize it
onto the ACES `fileshare` node at the declared destination.

The files were migrated from APTL's checked-in TechVault fixture directory and
remain non-sensitive synthetic training content. This directory is a content
source, not an inventory or alternate placement contract.
